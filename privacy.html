Privacy Policy

Spend Tracker · Last updated 1 November 2026

Spend Tracker is a personal application used only by its owner, Soumitra Mahakul ("I"). This policy explains how it handles data.

Data the app accesses

With my permission, the app uses Google's Gmail API with the read-only scope (gmail.readonly) to read transaction alert emails sent by my banks (HDFC Bank, ICICI Bank, Axis Bank) to my own Gmail account. From those emails it extracts the amount, date, card's last four digits, merchant name and reference number.

How the data is used

Only to show my own spending, billing cycles, budgets, categories and recurring charges in the app. The app does not send, delete or modify any email.

Where the data is stored

All extracted data and the Google sign-in token are stored locally on my own computer. They are not uploaded to any server or cloud service operated by the app.

Sharing

No data is sold, shared with third parties, or used for advertising. No data is used to train AI or machine-learning models.

Google API Services User Data Policy

Spend Tracker's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's local data folder removes all stored data.
